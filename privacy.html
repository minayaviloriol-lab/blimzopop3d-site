BLIMZOPOP 3D PUBLISHER

Privacy Policy

Last updated: October 22, 2026

This policy explains how BlimzoPop 3D Publisher handles information when its owner connects a TikTok account and uses the video draft upload features.

Information we process

  • Account information: basic TikTok profile information and account identifiers permitted by the access scopes the user authorizes.
  • Authorization tokens: access and refresh tokens needed to make authorized TikTok API requests.
  • Video content: videos and related information selected by the creator for draft upload.

How information is used

Information is used to connect the creator's TikTok account, identify the authorized account, and carry out video draft uploads requested by the creator. The project does not sell personal information.

Sharing

When the creator requests a draft upload, the necessary authorization and video data are transmitted to TikTok through its APIs. TikTok handles this information under its own terms and privacy policy. This project does not intentionally share account tokens with unrelated third parties.

Storage and security

The current integration is designed to run locally on the project owner's device. Authorization tokens are intended to be stored in a local configuration file with restricted file permissions, not in this public website or source repository. No method of storage is completely risk-free.

Retention and deletion

Local authorization tokens remain stored until the project owner deletes them or disconnects the integration. Users can revoke the application's access through TikTok's account settings. Drafts uploaded to TikTok are subject to TikTok's own storage and account controls.

Children's privacy

This project is not directed to children and is not intended for children under 13.

Changes and contact

This policy may be updated as the project changes. For questions, visit the project's GitHub page. Do not post passwords, access tokens, or other sensitive information in public issues.

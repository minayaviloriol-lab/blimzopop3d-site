BLIMZOPOP 2D STUDIO

Privacy Policy

Last updated: October 29, 2026

This policy describes the currently published BlimzoPop 2D Studio website. The website provides a local video preview and does not currently connect to TikTok or upload videos.

Information processed by this website

The video file selected for preview is handled by the browser for local playback. The website does not send that selected video to TikTok or to a BlimzoPop upload service. Do not select a file if you do not want it displayed in your browser session. The website does not ask visitors to enter TikTok credentials or authorization tokens.

Cookies and analytics

This project website is not designed to collect TikTok account data or video files. The hosting provider may process standard technical request information as part of delivering the website; consult the hosting provider's privacy information for details about its infrastructure.

Third-party services

This website links to project pages hosted by GitHub. Opening an external link takes you to that provider, whose own privacy terms apply. The current website version does not transmit video content or authorization tokens to TikTok.

Storage, retention and deletion

The website does not store selected video files on a BlimzoPop server. Local preview data remains in the browser session and can be cleared by closing or reloading the page. If a separate integration is introduced later, this policy should be updated before that integration collects or transmits personal information.

Children's privacy

This project website is not directed to children and is not intended for children under 13.

Changes and contact

This policy may be updated as the project changes. For questions, visit the project's GitHub page. Do not post passwords, access tokens, or other sensitive information in public issues.
